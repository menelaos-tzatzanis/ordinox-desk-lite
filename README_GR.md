# Ordinox Desk Lite

**Ελαφριά local-first εφαρμογή Windows για διαχείριση πελατών και καθημερινή οργάνωση μικρών επιχειρήσεων.**

[English](README.md) · [Ελληνικά](README_GR.md)

## Παρουσίαση

Το Ordinox Desk Lite είναι μια ελαφριά desktop εφαρμογή για Windows, σχεδιασμένη για μικρές επιχειρήσεις που χρειάζονται έναν απλό και πρακτικό τρόπο να διαχειρίζονται πελάτες, προϊόντα ή υπηρεσίες, τιμές, ιστορικό, έσοδα και καθημερινές επαγγελματικές πληροφορίες από ένα ενιαίο περιβάλλον.

Η εφαρμογή είναι σκόπιμα απλή και εστιασμένη. Απευθύνεται σε επιχειρήσεις που χρειάζονται περισσότερη οργάνωση από ένα spreadsheet ή διάσπαρτες σημειώσεις, χωρίς όμως την πολυπλοκότητα ενός μεγάλου συστήματος ERP ή CRM.

Ενδεικτικά μπορεί να χρησιμοποιηθεί από:

- Καταστήματα λιανικής
- Επιχειρήσεις παροχής υπηρεσιών
- Μικρές τοπικές επιχειρήσεις
- Επιχειρήσεις που λειτουργούν με ραντεβού
- Επιχειρήσεις που διατηρούν ιστορικό πελατών
- Επιχειρήσεις που χρειάζονται απλή παρακολούθηση προϊόντων, υπηρεσιών και εσόδων

Το παράδειγμα οπτικού καταστήματος που εμφανίζεται σε ορισμένα screenshots είναι **μία ενδεικτική διαμόρφωση της εφαρμογής**.

Η βασική ιδέα της εφαρμογής είναι πολύ ευρύτερη και μπορεί να προσαρμόζεται στις ανάγκες διαφορετικών επιχειρήσεων.

Το Ordinox Desk Lite ακολουθεί **local-first σχεδιασμό**, ώστε κατά την κανονική χρήση τα δεδομένα να αποθηκεύονται και να διαχειρίζονται τοπικά στη συσκευή Windows του χρήστη.

Είναι σχεδιασμένο για **Windows PCs και Windows tablets**, με υποστήριξη **Αγγλικού και Ελληνικού περιβάλλοντος**.

> **Portfolio showcase:** Αυτό το δημόσιο repository παρουσιάζει την εφαρμογή και το περιβάλλον εργασίας της. Ο production πηγαίος κώδικας διατηρείται ιδιωτικός και δεν δημοσιεύεται εδώ.

> **Demo δεδομένα:** Όλα τα ονόματα, στοιχεία πελατών, τιμές, εγγραφές και λοιπές πληροφορίες που εμφανίζονται στα screenshots είναι φανταστικά δεδομένα επίδειξης.

## Local-First Σχεδιασμός

Το Ordinox Desk Lite είναι σχεδιασμένο κυρίως για τοπική λειτουργία στη συσκευή Windows του χρήστη.

Για την κανονική χρήση:

- Δεν απαιτείται remote backend
- Δεν απαιτείται cloud database
- Δεν απαιτείται cloud account
- Τα δεδομένα αποθηκεύονται τοπικά
- Ο χρήστης μπορεί να δημιουργεί backup αρχεία
- Υπάρχει δυνατότητα restore/import
- Δεν απαιτείται συνεχής σύνδεση στο Internet

Αυτό το καθιστά κατάλληλο για επιχειρήσεις που προτιμούν μια απλή standalone desktop λύση.

## Τεχνολογία

Το Ordinox Desk Lite χρησιμοποιεί τεχνολογίες όπως:

- **Tauri 2**
- **Rust**
- **Vanilla JavaScript**
- **HTML5**
- **CSS3**
- **WebView local storage**
- **JSON**
- **CSV / spreadsheet-compatible exports**
- **Windows desktop packaging**
